# Project Notes

## Project
Sales Performance & Business Intelligence Dashboard

## Project Objective

This project aims to analyse sales data and develop a business
intelligence dashboard that provides insights into sales, revenue,
profitability, products, customers and regional performance.

## Analytical Approach

The project will follow an end-to-end data analytics workflow:

1. Data sourcing
2. Data understanding
3. Data cleaning and preparation
4. Exploratory data analysis
5. SQL analysis
6. Data modelling
7. DAX calculations
8. Power BI dashboard development
9. Insight generation
10. Business recommendations

## Key Business Questions

- What is the overall sales performance?
- What is the total revenue and profit?
- How does performance change over time?
- Which products perform best?
- Which regions perform best?
- Which customers contribute most to revenue?
- What areas require further investigation?
